# Вклад в проект SendVPN

Спасибо за интерес к проекту! Мы приветствуем любой вклад.

## Как внести вклад

### 1. Сообщить об ошибке

Если вы нашли ошибку:
1. Проверьте, не создан ли уже issue
2. Создайте новый issue с описанием проблемы
3. Укажите шаги для воспроизведения
4. Приложите логи если возможно

### 2. Предложить улучшение

1. Откройте issue с тегом `enhancement`
2. Опишите предлагаемую функцию
3. Объясните, почему это будет полезно

### 3. Отправить Pull Request

1. Fork репозитория
2. Создайте ветку для вашей функции:
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. Внесите изменения
4. Добавьте тесты если нужно
5. Commit изменения:
   ```bash
   git commit -m 'Add amazing feature'
   ```
6. Push в вашу ветку:
   ```bash
   git push origin feature/amazing-feature
   ```
7. Откройте Pull Request

## Стандарты кода

- Следуйте PEP 8
- Используйте type hints где возможно
- Добавляйте docstrings для функций
- Комментируйте сложную логику

## Добавление нового протокола

1. Откройте `config/protocols.py`
2. Добавьте протокол в `PROTOCOLS`
3. Убедитесь что категория существует
4. При необходимости добавьте парсер

## Добавление нового источника

1. Создайте класс парсера в `parsers/`
2. Унаследуйтесь от `BaseParser`
3. Реализуйте метод `parse()`
4. Добавьте в `GitHubMultiParser` или создайте новый

## Тестирование

```bash
pytest tests/
```
